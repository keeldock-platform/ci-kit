# Selection policy

Owner: CI maintainers. Validates exact Git identities, preserves deleted and renamed paths, applies conservative lock/unknown-input fallbacks, and refines the maintained affected-project set into independently selectable checks. One pack holds all invocations on each platform. Admission cannot use feedback restrictions or related-test filters; affected admission stays full until separately qualified.

`Plan` reads verified Git objects; `Select` accepts complete paths for offline policy fixtures. Both return private metadata. This package must not contain product-specific graphs, commands, credentials or hosted output formatting.
